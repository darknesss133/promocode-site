Мы разрабатываем прикладное программное обеспечение для промышленных контроллеров на языке программирования ST (входит в стандарт МЭК 61131-3). Практически всегда используем среду разработки CodeSys 3.5, включая различные ее варианты для конкретных контроллеров.

Также для программирования контроллеров используем язык FBD (входит в стандарт МЭК 61131-3), но значительно реже.

Для станций оператора используем SCADA системы АльфаРегул, Интраскада. При разработке прикладных программ для SCADA-систем приходится использовать скриптовые языки, например JavaScript.

Протокол передачи информации между программируемым контроллером и SCADA-системой - Modbus TCP, либо OPC UA.

При поддержке Фонда содействия инновациям по программе «Старт-ЦТ-1-2025 (очередь 2)» реализуется Разработка интеллектуального датчика факела на основе технологии машинного зрения для поддержания оптимального соотношения «газ-воздух» в многогорелочных котлах.
